## 🚀 Быстрый старт

 1. Клонируйте репозиторий
git clone 
cd inventory_bot

 2. Создайте виртуальное окружение (рекомендуется)
python -m venv venv
source venv/bin/activate  # Linux/macOS
#или
venv\Scripts\activate     # Windows

 3. Установите зависимости
pip install -r requirements.txt

 4. Настройте переменные окружения
cp .env.example .env
Отредактируйте .env, добавив BOT_TOKEN и другие параметры

 5. Запустите бота
python bot.py

## 📱 Использование
### 🔄 Основной сценарий
	1️⃣  /start → Выберите поликлинику
	2️⃣  Выберите кабинет из списка
	3️⃣  Укажите тип оборудования:
	    • 💻 Системный блок
	    • 🖥️ Монитор
	    • 🖨️ Принтер/МФУ
	    • 💼 Ноутбук
	    • 📦 Другое
	4️⃣  Заполните поля:
	    ├─ 📛 Наименование
	    ├─ 🔢 Серийный номер
	    ├─ 🏷️ Инвентарный номер
	    ├─ 🌐 IP / MAC адрес (опционально)
	    ├─ 🪟 ОС (Windows 10/11/Linux)
	    ├─ 🛡️ Dr.Web установлен? Да/Нет
	    ├─ 📝 Office установлен? Да/Нет
	    └─ 📌 Примечание
	5️⃣  ✅ Сохранить запись
	6️⃣  🖨️ Распечатать этикетку (опционально)

### 🔐 Безопасность

- 🔑 Доступ к боту ограничен по `chat_id` — только авторизованные пользователи
- 👑 Административные команды защищены дополнительной проверкой ролей
- 🗄️ База данных хранится локально, без передачи во внешние сервисы
- 🚫 Файл `.env` с секретами исключён из системы контроля версий

### 🔒 Рекомендации по развёртыванию
1. Храните `.env` в защищённом месте с ограниченным доступом
2. Регулярно делайте бэкапы папки `data/`
	# Пример бэкапа (Linux)
	tar -czf backup_$(date +%Y%m%d).tar.gz data/
3. Обновляйте зависимости: `pip install --upgrade -r requirements.txt`
