# Inventory Bot

Инвентаризационный бот для управления складом.

## Развертывание на VPS с помощью Docker

### Требования
- VPS с Ubuntu/Debian/CentOS
- Docker и Docker Compose установлены
- Доменное имя (опционально)

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/avvinogra/inventory_bot.git
cd inventory_bot
```

2. **Настройте окружение:**
- Создайте файл `.env` на основе `.env.example` (если есть)
- Настройте параметры подключения к Telegram и другие переменные окружения

3. **Соберите и запустите контейнеры:**
```bash
docker-compose up -d --build
```

4. **Проверьте работу:**
```bash
docker logs -f inventory-bot
```

### Обновление

1. Остановите текущие контейнеры:
```bash
docker-compose down
```

2. Обновите код:
```bash
git pull
```

3. Пересоберите и запустите:
```bash
docker-compose up -d --build
```

### Структура проекта

- `bot.py` - Основной файл бота
- `config.py` - Конфигурация
- `database.py` - Работа с базой данных
- `data/` - Хранение базы данных (автоматически создается)
- `labels/` - Генерация штрихкодов (автоматически создается)
- `templates/` - Веб-интерфейс

### Примечания

- Данные базы и сгенерированные штрихкоды сохраняются в volumes и сохранятся при обновлении
- Для бэкапа данных используйте файлы в папке `data/`
- Веб-интерфейс доступен по адресу, указанному в конфигурации
